## 2️⃣ Basic component tree

Radix UI components are *unstyled* primitives. You compose them and apply your own CSS (or a utility‑class framework like Tailwind).

```tsx
import * as DropdownMenu from '@radix-ui/react-dropdown-menu';
import { ChevronDownIcon } from '@radix-ui/react-icons';

export const SimpleDropdown = () => (
  <DropdownMenu.Root>
    {/* Trigger – anything that can receive a click/focus */}
    <DropdownMenu.Trigger asChild>
      <button className="inline-flex items-center gap-1 rounded bg-gray-100 px-3 py-1">
        Options <ChevronDownIcon />
      </button>
    </DropdownMenu.Trigger>

    {/* The portal moves the menu to the end of <body> (good for overflow) */}
    <DropdownMenu.Portal>
      {/* Content – the floating panel */}
      <DropdownMenu.Content
        className="min-w-[180px] rounded-md bg-white shadow-md ring-1 ring-black/5"
        sideOffset={5}               // distance from trigger
        align="start"                // left‑aligned (can be "center"/"end")
      >
        {/* Each item is a button by default */}
        <DropdownMenu.Item
          className="px-4 py-2 text-sm hover:bg-gray-100 focus:bg-gray-100 focus:outline-none"
          onSelect={() => alert('Profile clicked')}
        >
          Profile
        </DropdownMenu.Item>

        <DropdownMenu.Item
          className="px-4 py-2 text-sm hover:bg-gray-100 focus:bg-gray-100 focus:outline-none"
          onSelect={() => alert('Settings clicked')}
        >
          Settings
        </DropdownMenu.Item>

        {/* Separator */}
        <DropdownMenu.Separator className="my-1 h-px bg-gray-200" />

        {/* Disabled item */}
        <DropdownMenu.Item
          disabled
          className="px-4 py-2 text-sm text-gray-400"
        >
          Disabled option
        </DropdownMenu.Item>

        {/* Sub‑menu (nested) */}
        <DropdownMenu.Sub>
          <DropdownMenu.SubTrigger className="flex items-center justify-between px-4 py-2 text-sm hover:bg-gray-100 focus:bg-gray-100">
            More…
            <ChevronDownIcon className="ml-2" />
          </DropdownMenu.SubTrigger>

          <DropdownMenu.Portal>
            <DropdownMenu.SubContent
              className="ml-2 min-w-[150px] rounded-md bg-white shadow-md ring-1 ring-black/5"
              sideOffset={2}
            >
              <DropdownMenu.Item
                className="px-3 py-2 text-sm hover:bg-gray-100 focus:bg-gray-100"
                onSelect={() => alert('Help clicked')}
              >
                Help
              </DropdownMenu.Item>
            </DropdownMenu.SubContent>
          </DropdownMenu.Portal>
        </DropdownMenu.Sub>
      </DropdownMenu.Content>
    </DropdownMenu.Portal>
  </DropdownMenu.Root>
);
```

### Key parts explained

| Component | What it does |
|----------|--------------|
| `DropdownMenu.Root` | Holds the whole widget and manages open/close state. |
| `DropdownMenu.Trigger` | The element that toggles the menu (usually a button). Use `asChild` to keep your own button element. |
| `DropdownMenu.Portal` | Renders children at the end of `<body>` to avoid clipping. |
| `DropdownMenu.Content` | The floating panel that appears. Props like `sideOffset`, `align`, `collisionPadding` help with positioning. |
| `DropdownMenu.Item` | Clickable actions. `onSelect` fires when the user chooses the item (via click or keyboard). |
| `DropdownMenu.Separator` | Visual divider. |
| `DropdownMenu.Sub`, `DropdownMenu.SubTrigger`, `DropdownMenu.SubContent` | Nest a submenu. |
| `DropdownMenu.CheckItem` / `DropdownMenu.RadioItem` | Built‑in check‑box or radio‑style items (optional). |
| `DropdownMenu.Arrow` | Small arrow pointing to the trigger (optional). |

## 3️⃣ Styling tips

* **Tailwind** (as in the example) works great because Radix only provides functionality, not CSS.
* If you prefer plain CSS, give each component a class name and style it in a `.css` or `.module.css` file.
* For animations, wrap `DropdownMenu.Content` with `@radix-ui/react-transition` or use CSS `@keyframes` + `data-state` attributes (`open` / `closed`).

```css
/* Example: fade‑in animation */
[data-state="open"] {
  animation: fadeIn 120ms ease-out forwards;
}
[data-state="closed"] {
  animation: fadeOut 120ms ease-in forwards;
}
@keyframes fadeIn { from { opacity: 0; } to { opacity: 1; } }
@keyframes fadeOut { from { opacity: 1; } to { opacity: 0; } }
```

## 4️⃣ Controlled vs. uncontrolled usage

Radix components are *uncontrolled* by default (they manage their own open state). If you need to control it (e.g., sync with a global UI store), use the `open` and `onOpenChange` props on `DropdownMenu.Root`.

```tsx
const [open, setOpen] = React.useState(false);

<DropdownMenu.Root open={open} onOpenChange={setOpen}>
  {/* ... */}
</DropdownMenu.Root>
```

## 5️⃣ Keyboard navigation (built‑in)

* **Enter / Space** – activate the highlighted item.
* **Esc** – close the menu.
* **ArrowDown / ArrowUp** – move between items.
* **Right Arrow** – open a submenu; **Left Arrow** – close a submenu.

Radix handles all of this automatically, so you don’t need extra code.

---

## 6️⃣ Common pitfalls & how to avoid them

| Issue | Fix |
|-------|-----|
| Menu gets clipped by a parent `overflow: hidden` | Wrap the menu in a `DropdownMenu.Portal` (as shown) so it’s rendered at the document root. |
| Click on a disabled item still triggers `onSelect` | Ensure you pass the `disabled` prop; Radix prevents the event automatically. |
| Sub‑menu opens on hover but you want click‑only | Use `DropdownMenu.SubTrigger` with `asChild` and attach a click handler, or set `defaultOpen={false}` and control it manually. |
| Styling isn’t applied because you forgot `asChild` | For custom button markup, always add `asChild` to the Trigger (or any sub‑component) so Radix forwards its props (including `ref` and event handlers). |

## 7️⃣ Full minimal example (TSX)

```tsx
// src/components/DropdownMenuExample.tsx
import * as React from 'react';
import * as DropdownMenu from '@radix-ui/react-dropdown-menu';
import { ChevronDownIcon } from '@radix-ui/react-icons';

export const DropdownMenuExample: React.FC = () => (
  <DropdownMenu.Root>
    <DropdownMenu.Trigger asChild>
      <button className="rounded bg-blue-600 px-4 py-2 text-white hover:bg-blue-700">
        Open menu <ChevronDownIcon />
      </button>
    </DropdownMenu.Trigger>

    <DropdownMenu.Portal>
      <DropdownMenu.Content
        className="min-w-[200px] rounded-md bg-white p-1 shadow-lg ring-1 ring-black/5"
        sideOffset={5}
      >
        <DropdownMenu.Item
          className="px-3 py-2 text-sm hover:bg-gray-100 focus:bg-gray-100"
          onSelect={() => console.log('New file')}
        >
          New file
        </DropdownMenu.Item>

        <DropdownMenu.Item
          className="px-3 py-2 text-sm hover:bg-gray-100 focus:bg-gray-100"
          onSelect={() => console.log('Open file')}
        >
          Open file
        </DropdownMenu.Item>

        <DropdownMenu.Separator className="my-1 h-px bg-gray-200" />

        <DropdownMenu.Sub>
          <DropdownMenu.SubTrigger className="flex items-center justify-between px-3 py-2 text-sm hover:bg-gray-100 focus:bg-gray-100">
            More options
            <ChevronDownIcon className="ml-2" />
          </DropdownMenu.SubTrigger>

          <DropdownMenu.Portal>
            <DropdownMenu.SubContent
              className="ml-2 min-w-[150px] rounded-md bg-white p-1 shadow-md ring-1 ring-black/5"
              sideOffset={2}
            >
              <DropdownMenu.Item
                className="px-2 py-1 text-sm hover:bg-gray-100 focus:bg-gray-100"
                onSelect={() => console.log('Export')}
              >
                Export
              </DropdownMenu.Item>
            </DropdownMenu.SubContent>
          </DropdownMenu.Portal>
        </DropdownMenu.Sub>
      </DropdownMenu.Content>
    </DropdownMenu.Portal>
  </DropdownMenu.Root>
);
```

Paste the component into a React page, import it, and you have a fully functional dropdown menu with keyboard support, sub‑menus, and easy styling.
